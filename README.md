# Flappy Face 🐦

A tap-to-fly browser game where the hero is **your friend's face**.

- Tap / click / Space to flap through the candy-striped towers
- Upload any photo; it gets cropped into a circle and saved in your browser
- Type your friend's name and the title becomes **FLYING <NAME>**, plus custom roasts on game over
- Best score, medals, sound effects (toggle 🔊), works on phones

## Bake in your friend's face
Put a square-ish photo named `friend.png` next to `index.html`. It becomes the default face for everyone who opens the game.

## Run
Just open `index.html` in a browser. It's one file with no build step.

## Deploy (free)
- **GitHub Pages:** Settings → Pages → Deploy from branch → pick the branch → `/ (root)`
- **Cloudflare Pages / Netlify:** drag-and-drop the folder
